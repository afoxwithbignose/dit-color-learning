00ADVANCED MINDSET / 进阶判断
FROM OUTPUT TO INTENT

进阶不是“更难的工具”，
是更清楚的选择。

基础阶段解决“参数在哪里”；进阶阶段解决“为什么是这个参数，它和其他镜头如何组成一个世界”。审美让你知道方向，技术让你能把方向稳定地交给观众。

审美不是主观借口，技术也不是客观终点。真正可靠的调色，是能被感受、被解释、被复现，并在连续镜头中保持一致。

02AESTHETIC LEARNING / 审美学习法
DAILY PRACTICE · 15 MIN

审美不是“多看图”，
是有结构地看图。

每天浏览一百张图，不如认真拆解三张。先不看滤镜名，不猜 LUT。按“光、形、色、质、空间、叙事”六层观察，把模糊感受转成可比较的判断。

避免只说“高级”：高级在哪里？低饱和、大留白、硬光、冷背景衬托暖皮肤，还是高光滚降柔和？说清楚才有学习价值。

01 / LIGHT

光

方向、软硬、反差、色温、光源动机。先判断主体是被主光塑造，还是被环境光吞没。

02 / FORM

形

视线路径、几何、留白、遮挡、画面重量。色彩调色并不能修复所有构图问题。

03 / COLOR

色

主色、辅色、是否对立、肤色如何被环境反射、颜色如何分区。不要用色相环简单解释所有情绪。

04 / TEXTURE

质

锐度、柔和度、颗粒、光晕、镜头缺陷与高光滚降。质感应当可以解释来源。

05 / SPACE

空间

前中后景是否靠亮度、饱和度、色相或清晰度分离。主体是否从背景里“长出来”。

06 / STORY

叙事

颜色为什么出现在这个时刻？它制造安全、疏离、怀旧、危险还是希望？没有叙事目的的“风格”很脆弱。

15-MINUTE EYE DRILL

每天三张图，建立审美语料库

不是收藏图片，而是训练注意力和语言。每张只写一句事实、一句因果和一个可尝试的技术动作。

01眯眼 5 秒

只看大块的明暗与视线落点。

02说 3 个词

避开“高级、好看”，只描述可观察特征。

03找 1 个因果

为什么视线会停在那里？

04写 1 个动作

视觉判断小练习

点选你认为更符合题干要求的画面，查看解释。练习不追求唯一正确答案，而追求能否说出判断依据。

DRILL 01

哪一张有更明确的视觉焦点？

视觉焦点来自对比的集中，而不是颜色数量。暖光、亮度和背景低饱和共同让视线集中到主体上。

DRILL 02

哪一张更保留暗部结构？

风格化压暗不是把暗部全部切掉。保留一点结构与环境色，画面通常更有层次，也更有后期调整余地。

DRILL 03

哪一种冷暖关系更有空间分离？

冷暖分离只是分离手段之一。它的价值在于让主体与空间关系清楚，而不是机械地把所有阴影变青、高光变橙。

03REFERENCE DECONSTRUCTION / 参考片拆解
SEE THE CAUSE · NOT THE FILTER

一张参考画面里，
至少同时有六件事在发生。

亮度决定视线，色彩分配情绪，光位塑造体积，材质建立年代与媒介感，运动改变阅读顺序，叙事决定哪些“好看”值得保留。

01

把观感拆成事实

“温暖”要拆成哪块区域偏暖、暖了多少、与什么颜色对比；“柔”要拆成高光滚降、低微反差和颗粒。

02

区分内容与调色

服装、灯光、美术和镜头本身已经贡献了风格。不要把所有差异都塞进节点里。

03

按因果排序

先解决输入空间，再调曝光、对比、色彩关系、局部与质感。顺序错了，复现会变得不可解释。

04

做差异清单

列出当前画面与参考的亮度、色相、饱和度、肤色、空间和质感差异，再逐项处理。

04TECHNICAL REPRODUCTION / 技术复现
LAYER BY LAYER · MEASURE · VERIFY

复现不是复制像素，
是重建一条选择路径。

参考截图可能经过压缩、显示转换和平台映射，不能直接当成“真相”。先建立色彩管理的共同语言，再按亮度、色彩、局部和质感拆层级，最后在同一场景里检验泛化。

相似度不是创作目标。交互分值只是参数接近度示意，真实的像素比较还要考虑显示转换、镜头、颗粒与内容差异。技术复现的终点，是在自己的素材上保持同样的视觉逻辑。

复现的正确顺序

01

统一观看条件

把参考和目标置于同一色彩管理、同一显示转换、相近亮度环境。不要拿未管理的网页截图直接比对。

02

先匹配明暗

看大块亮度关系、黑位、白位和高光分布。眯眼比对可以减少颜色对明度判断的干扰。

03

再匹配色彩

确定主色、辅色、肤色与环境色，不要先追单个色相。用分区和范围判断，而不是全文偏色。

04

最后做质感

重建滚降、Halation、Bloom 与 Grain，并检查它们在运动中的稳定性。

05

脱离参考检验

换一张同场景素材，应用你的节点逻辑。只在参考画面上成立，说明你做的是贴图，不是风格。

06

记录可复现配方

保存节点、Still、LUT、色彩空间、项目设置和版本，让第二个人能够重建你的结果。

05ADVANCED TOOLS / 高级方法与节点
TECHNIQUE · COMPLEXITY WITH PURPOSE

高级技术不是更复杂，
而是更精确地控制关系。

在色彩管理明确的前提下，色彩变换、色域映射、局部分离、合成与质感才有意义。节点的复杂度必须带来可控性，而不是让故障难以定位。

01 / HUE × LUM

Hue vs Luminance

控制特定色相区间的明度，让蓝天、肤色、植物或霓虹光拥有独立层次。先看上下文，避免产生不自然色块。

Targeted tonal separation
02 / GAMUT

Gamut Mapping

把超出目标显示范围的颜色有序压回，而不是粗暴削掉。不同映射策略会影响高饱和高光的色相与细节。

Perceptual / compress / clip
03 / TONE

Tone Mapping

在高动态范围与显示目标之间分配亮度，保护高光层次与面部。不能把所有高光都压成一个平灰面。

Shoulder / roll-off / pivot
04 / MATTE

Composite Logic

限定器、窗口、跟踪和 Layer Mixer 共同决定局部结果。先看 Matte，再评价颜色；遮罩错了，颜色再好也不成立。

Key → Clean → Track → Mix
05 / HDR

HDR / SDR Trim

用受控的 trim pass 管理不同亮度版本的相对关系。不要用一个 LUT 同时解释所有显示目标和观看环境。

PQ / HLG / 100-nit SDR
06 / FINISH

Grain & Halation

颗粒大小、强度与高光扩散应随镜头、分辨率和输出而变。目标是建立媒介感，不是给每个镜头打同一层噪点。

Scale-aware texture

08REPRODUCTION TROUBLESHOOT / 复现故障手册
COMPARE · ISOLATE · GENERALIZE

像但又不对，
先找“哪一层不像”。

复现失败通常不是缺少某个 LUT，而是参考与目标处于不同的观看条件，或把光、材质、内容和调色混为一谈。用差异层级来定位。

症状优先怀疑最小验证处理
整体就是“不像”显示条件 / 内容差异同屏、同亮度、同色彩标签比较先统一观看端，再拆解技术差异
亮度对了但层次不对对比曲线 / Pivot眯眼比较黑白块与中间调调整 Pivot、滚降与局部对比
颜色接近但空间塌主辅色 / 饱和度分布只保留大色块比较降低背景竞争，重建冷暖或色相分离
肤色很脏混合色 / 色相压缩切换 Matte，查看肤色区域与环境反射修白点，限制绿色偏移，保护高光
单帧很像，连续播放跳缺少 Hero 和镜头连续策略三镜循环播放统一黑位、白点、肤色与风格强度
换素材就失效过拟合 / 节点逻辑不泛化用不同光线的新素材测试把风格拆成可调参数与相对关系
质感像塑料Halation / Grain / 高频处理100% 局部看高光与微反差降低全局处理，按镜头和分辨率调整
输出后又不像输出变换 / 编码 / 标签回读实际输出文件比较修复显示变换与交付规格，不只信 Viewer
RULE OF THREE

至少用三张不同的参考画面、三条自己的素材和一个实际输出文件来验证风格。单张像，不代表方法成立。

Q1 / AESTHETIC

客户说画面“不够高级”，最合理的下一步是？

“高级”不是可执行参数。将模糊反馈转成视觉事实和参考，是审美沟通与技术执行之间最重要的一步。

Q2 / REPRODUCTION

单帧复现很像，但同场景下一镜头完全失效，说明什么？

真正可复现的是相对关系与调整策略，不是某张截图上的像素结果。用不同素材测试，才能验证风格逻辑。

Q3 / WORKFLOW

复现参考时，哪条顺序最合理？

观看条件先统一，技术转换先正确，再处理大关系、局部和质感。这个顺序让每个差异都可定位、可复盘。
