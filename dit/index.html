00ROLE / 明确 DIT 的职责边界
PREP · 先对齐再上机

DIT 不是“高级拷卡员”，
也不是片场调色师。

DIT 是摄影、数据、色彩和后期之间的人。你既要让素材安全、完整、可追溯，也要用正确的技术转换与监看环境，让导演、摄影指导看到可信的画面，并把现场创作意图准确交给后期。

一句可验收的职责：在不改变素材原始信息的前提下，保证每一次拍摄都能被正确监看、可靠备份、快速检索，并在当天准确送达剪辑与调色。

01INGEST / 从接卡到可交付素材
CRITICAL · 不可重拍

你接过的不是文件，
是剧组无法重来的表演。

拷卡不是把文件拖进硬盘。正确顺序是：确认来源、只读接入、保留原始结构、复制工作副本、建立独立备份、校验哈希、抽检播放、登记报告，最后才按流程清卡。

不要用“复制完成”代替“已验证”。文件数与容量一致只是最低检查，仍然需要内容哈希和实际解码。

01

停录、确认、登记来源

等摄影机停止写入并安全断电或弹出介质。记录拍摄日、摄影机机号、卡号、卷号、场镜次、帧率、编码、卡容量和交卡人。卡与电子台账使用同一个唯一编号。

02

只读接入，检查源卡健康

优先使用可靠读卡器和稳定供电，避免 HUB 串联。核对源卡卷标、文件夹数量与文件数；出现 I/O 报错、异响或容量异常时立即停止，保留原卡，不执行“修复并写回”。

DIT / Loader
03

按不可变目录契约复制

推荐：PROJECT/2026-10-26/CAM_A/ROLL_001/CARD_001/。保留相机的原始目录和文件名；代理、报告、LUT、声音和 Dailies 各自进入独立目录，通过清单关联。

DIT
04

建立主工作副本与独立备份

A 副本供现场处理，B 副本进入不同物理介质或异地存储。不要在主副本上直接改名原片；不要对源卡使用镜像删除式命令。

DIT
05

哈希校验源文件与两份副本

对源、A、B 分别计算内容哈希并比对；同时核对文件数、总字节、目录结构。大批量项目可使用专业 Offload 软件和 xxHash 提高速度，但必须保存校验报告。

# Windows / PowerShell：按相对路径生成一目录的哈希清单
function Get-TreeHash([string]$Root) {
  $Base = (Resolve-Path $Root).Path.TrimEnd('\')
  Get-ChildItem $Root -File -Recurse | ForEach-Object {
    [pscustomobject]@{
      RelativePath = $_.FullName.Substring($Base.Length).TrimStart('\')
      Hash = (Get-FileHash $_.FullName -Algorithm SHA256).Hash
    }
  }
}
Get-TreeHash "D:\CARD\DCIM" | Sort-Object RelativePath |
  Export-Csv ".\source_hashes.csv" -NoTypeInformation -Encoding UTF8

# 对 A、B 副本分别生成清单，再按相对路径和哈希比对
Compare-Object (Import-Csv ".\source_hashes.csv") `
  (Import-Csv ".\copy_a_hashes.csv") -Property RelativePath,Hash

02IMAGE PIPELINE / 曝光、色彩与监看
ON SET · 让画面“看得对”

记录的是数据，
监看的是解释。

01

曝光看数据，不只看亮度

结合波形图、伪色、斑马纹、高光保护策略与相机原生基准判断。RAW 的 EI 是监看/元数据策略，不等同于简单提高传感器物理 ISO。

02

LUT 分职责

技术转换 LUT 解决 Log 到显示空间的映射；Show LUT 表达现场创作方向；风格 LUT 可能带有强烈的对比与偏色。文件名和版本必须可追溯。

03

监视器是链条的一部分

同一 LUT 在不同亮度、色域、Gamma 和遮光条件的屏幕上会不一样。现场监视器要校准，环境漏光与背景墙颜色也会影响判断。

EXPOSURE NOTES

现场常见曝光抓手

  • 波形图：看亮度分布与高光是否触顶，不把监视器亮度当曝光表。
  • 伪色：快速定位肤色、中灰和高光；不同相机/监看工具阈值可能不同。
  • 斑马纹：适合检查可控高光区，但不能代替全画面波形。
  • EI：记录每次变化，避免同一场镜头因无记录改变可调空间。
  • 窗格与实用光：高光可能先于人脸触顶，保护策略要服从后期与创作意图。

06TROUBLESHOOT / 片场故障手册
STOP · ISOLATE · RECORD

不要“试一下再说”。
先定位在哪一层。

按源卡、读卡链路、复制目标、解码、监看、声音、网络逐层排查。每次只改一个变量；涉及源卡写入、格式化或修复的操作必须先停下并上报。

症状优先怀疑最小验证处理
源卡读不到读卡器 / 供电 / 介质换可靠读卡器，只读测试保留原卡；禁止写入式“修复”
文件数对上但哈希错传输损坏 / 同名覆盖比对单文件哈希与大小从源卡重拷到新目录；记录异常
画面全黑或花屏解码 / 显卡驱动 / 代理播原片、换解码器、换机器先判断源问题还是播放环境问题
现场颜色和后期不同LUT 顺序 / 色彩空间 / 校准固定素材与截图逐层 bypass核对 IDT、Show LUT、ODT 与监看模式
声音不同步TC 偏移 / 帧率 / 起录点拍板帧与声音波形逐帧对齐记录偏移；避免代理与声音二次漂移
高光异常溢出曝光 / EI / 监看 LUT用原始信号看波形与伪色区分源数据溢出与 LUT 显示裁切
传输速度突然下降缓存耗尽 / 热降速 / 线材同一卡小文件批量测速检查目标盘剩余空间、温度与链路
Dailies 上传失败网络 / 命名 / 平台规格本地播放 + 单条小文件上传保留待传队列；完成回执才关闭任务
EMERGENCY RULE

任何涉及源卡写入、清卡、覆盖或格式化的操作，都先确认两份独立备份与播放抽检。现场压力越大，越要把这一步写下来。

POCKET GLOSSARY

片场 DIT 口袋词表

DIT
Digital Imaging Technician，负责数字影像技术、数据与色彩监看流程。
Offload
从相机介质复制、校验并登记素材的工作。
Checksum
用哈希验证源与副本内容一致，比文件大小更可靠。
Show LUT
现场监看/审片用 LUT，表达创作方向，不等于最终调色。
CDL
ASC Color Decision List，用标准化参数传递初级调色决定。
ACES
可扩展的学院色彩编码系统，以场景参考与 ODT 管理显示转换。
EI
Exposure Index，RAW 工作流中常用于调整监看与高光分配的曝光指数。
Burn-in
叠加在 Dailies 上的场镜次、TC、相机等参考信息。
Proxy
供剪辑浏览的低码率替身文件，需可回套原片。
Dailies
每日审片/剪辑参考版本，不是最终调色成片。
QCKNOWLEDGE CHECK / 三题自测
FIELD CHECK · 3 MIN

你真的会把一张卡
安全送到后期吗？

答完立即得到解释。三条底线分别对应素材安全、色彩解释和现场交接。

0/ 3 CORRECT
Q1 / 拷卡

什么时候可以格式化摄影机原卡？

原卡是不可重拍的源证据。两份独立备份、完整性校验、播放抽检、报告与授权都完成后，才进入剧组规定的清卡步骤。

Q2 / 色彩

现场监视器上套 Show LUT 后画面好看，说明什么？

Show LUT 是监看解释，不是原片重写。必须记录 LUT 版本、输入/输出色彩空间、监视器和应用顺序，后期才能复现。

Q3 / Dailies

发现某条素材声音错位 2 帧，正确做法是什么？

异常要可搜索、可定位、可关闭。保留原片，记录偏移与同步参考，修复应发生在代理/交付副本并留下新版本。
