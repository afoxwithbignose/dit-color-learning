00JUDGEMENT / 建立调色判断
FOUNDATION · 先看关系

调色不是给画面加滤镜，
是控制注意力与意义。

观众不会先看到你的节点，而会先感受到光线、肤色、空间和情绪。一个好的镜头要回答：第一眼应该看哪里？哪里像白？前后景如何分离？颜色在叙事里承担什么？

调色顺序的核心不是软件按钮，而是从“技术正确”到“感知平衡”，再到“镜头关系”与“创作表达”的逐层收敛。
LEVEL 01

技术正确

色彩空间、Gamma、数据范围、位深、交付转换正确。画面没有黑位裁切、色域误解或重复转换。

可量化
LEVEL 02

感知平衡

曝光、对比、白平衡与饱和度形成自然、可信的观看起点，眼睛有明确的落点。

可观察
LEVEL 03

镜头关系

同一场景的镜头在明暗、色温、肤色、空间感和连续性上彼此匹配，剪辑不跳。

可比较
LEVEL 04

创作表达

色彩与叙事一致。风格服务题材、人物与情绪，而不是盖住原片的信息和质感。

可感受
THE PRIMARY QUESTION

“我为什么要动这个参数？” 为了恢复信息、统一接戏、突出主体、分离空间，还是建立情绪？如果答不出来，先关掉节点，重新看画面。

01

先补偿，再创作

先校正拍摄变化与色彩管理，再决定 Contrast、Split Tone 和 Film Look。不要把技术问题藏在风格里。

02

一个节点一件事

曝光、白平衡、Look、局部塑形分开控制。故障时可单独 Bypass，改版本时不至于拆掉整条链。

03

示波器与眼睛并用

示波器保证不越界、不偏色；眼睛判断画面是否有层次、肤色与情绪。两者不是替代关系。

04

始终比较镜头

单镜头漂亮不代表场景成立。建立 Hero Shot，再让其他镜头向它靠近，而不是每张图各自“出片”。

02COLOR SCIENCE / 色彩与观察基础
WHY · 看懂工具在改什么

颜色不是像素属性，
是光、材料、眼睛和解释的共同结果。

调色软件处理的是数字编码，观众看到的是经过监视器或屏幕重建的光。理解场景参考、显示参考、编码曲线和色域边界，才不会把“画面偏灰”误判成“素材坏了”。

01Light光谱与照度
02Camera传感器与编码
03Grade关系与意图
04Display亮度与色域

01

Hue / Saturation / Value

色相是颜色类别，饱和度是纯度，明度/亮度是强弱。三者在感知上相互影响：高亮色更容易显得低饱和，强背景会改变肤色观感。

02

Scene / Display Referred

场景参考描述拍摄现场的光；显示参考描述某块显示设备上的输出。RAW/Log 不是最终观看状态，必须经过正确的显示转换。

03

Gamut / Gamma

色域决定可表达的色相与饱和度边界，Gamma/传递函数描述编码与亮度之间的关系。两者不是同一个设置。

04

Bit Depth / Precision

位深影响可分辨的量化阶数。10-bit 比 8-bit 更耐拉、更少色带；浮点处理有利于高动态范围和反复运算。

05

Memory Color

人眼对肤色、天空、草地与中性灰有记忆。它们不必数值相等，但必须看起来“可信”。肤色尤其不能被简单当作固定 RGB 数值。

06

Simultaneous Contrast

同一块颜色放在不同背景中会显得不同。判断肤色与饱和度时，要看周围环境、镜头连续性和观看环境，而不是孤立盯一个像素。

SCOPE READING / 示波器

波形看亮度，矢量看关系。

示意图，不对应特定素材
WAVEFORM

亮度波形：观察黑位、高光与中间调的分布；不是越铺满越好。

RGB PARADE

RGB Parade：比较 R/G/B 的黑白位与中间段，判断中性灰与偏色。

VECTORSCOPE

Vectorscope：观察色相方向与饱和度强度；肤色线只是参考，不是硬性目标。

READ THIS

波形和矢量图读的是信号关系。示波器设置、数据范围、时间线色彩空间与参考级别都会改变读数。调色前先确认项目色彩管理，再用示波器辅助判断。

03COLOR MANAGEMENT / 项目色彩管理
FOUNDATION · 一次正确的解释

调色前，先回答
“这个数是什么颜色？”

如果输入、工作与显示空间不清楚，所有 Lift、Gamma、Gain 与 LUT 都可能建立在错误解释上。色彩管理的任务，是让每个像素从拍摄到观看有明确、唯一的转换路径。

最常见错误：输入转换、Look LUT、输出转换重复套用，导致对比被二次压缩、黑色漂浮或肤色过黄。

NON-NEGOTIABLE RULES

色彩管理六条底线

  1. 识别媒体：确认每个源片段实际使用的相机色彩空间和 Gamma。
  2. 一次输入：只需要一次从源空间到工作空间的转换。
  3. 一次输出：输出变换只应用一次，避免节点与项目设置重复处理。
  4. 匹配观看端：显示变换必须与监视器、亮度和色域一致。
  5. 冻结版本：LUT、CDL、项目设置与 Resolve 版本进入交付记录。
  6. 分开技术/创作：色彩空间变换与 Look 放在不同节点，方便诊断与迁移。
04TOOLKIT / Color Page 工具箱
RESOLVE · 工具服务于问题

不是哪个工具强，

01 / PRIMARY

色轮与全局关系

Lift / Gamma / Gain 分布调整暗部、中间调与高光；Offset 更均匀地推移整体。先用它们建立曝光、白平衡与色调基底。

02 / CURVES

用分布而不是猜数值

Custom 曲线控制亮度与通道；Hue vs Hue/Sat/Lum 精确调整某段色彩关系。曲线形状应能解释，不要随机打点。

Luma · Hue · Saturation
03 / QUALIFIER

选择颜色相似区域

HSL 限定器配合 Matte Finesse、Clean Black/White 与 Toggle Matte 检查选区。范围一旦过大，肤色和背景会一起被带走。

Hue · Saturation · Luminance
04 / WINDOW

选择空间区域

Power Window 做局部光线、天空、脸部与空间引导。羽化、反向、柔化与跟踪决定它是否自然。

Shape · Feather · Track
05 / WARP

改变色彩拓扑

Color Warper 适合重新定位一组颜色、修正混合色或做风格化分离。它解决的是色彩位置关系，不只是整体偏色。

Hue × Saturation lattice
06 / MASK

比追踪更聪明的选区

Magic Mask、深度图与对象遮罩适合复杂运动，但必须检查边界、遮挡与运动模糊。自动工具提高效率，不替代 QC。

Object · Person · Depth
TOOL ORDER / 一个小原则

先全局，后局部，最后质感

  • 全局：曝光、对比、白平衡、整体饱和度。
  • 关系：肤色与环境分离、前后景层次、关键色。
  • 局部：窗口、面部、天空、实用光与视线引导。
  • 质感：Film Grain、Halation、Bloom、Gate Weave。
  • 交付：最后检查输出变换与编码，不在末端补偿前面的错误。
05NODE ARCHITECTURE / 节点不是装饰
SYSTEM · 每一步可解释

好的节点图，
是能拆开检查的思路。

节点让每个操作独立、可复用、可旁路。节点越多不代表越专业；真正专业的是命名清楚、职责单一、信号流正确，并且能准确解释第 4 个节点为什么存在。

01

Serial 串联

前一个节点的结果进入后一个节点，适合连续校正和递进风格。

A→B→C
02

Parallel 并行

多个节点从同一输入出发，经 Layer Mixer 合成，适合比较或混合 Look。

A╲B╱Mix
03

Layer 图层

使用 Alpha/Key 把前景结果叠在背景上，适合局部颜色与质感。

BG+FG=Mix
04

Key Mixer

组合多个 Key，改进遮罩的覆盖与排除关系。优先检查 Matte，不要先修饰。

SIX PASSES · 顺序比速度重要

先做全场，再做单镜；

BALANCE LAB / 交互练习

先不调风格，把画面调“可信”。

下面的模拟器不替代 Resolve 的示波器，而是帮助你建立参数与画面的直觉：曝光推动整体，色温改变 R/B 平衡，色调改变 Green/Magenta 倾向。

NEUTRALSIMULATION · NOT A SCOPE
01

选 Hero Shot

选择场景里最具代表性、主体清晰、最容易建立观看基准的镜头。先把它调到满意，再匹配其他镜头。

02

先统一黑与白

用 RGB Parade 和波形比较黑位、白点和中间亮度。不要让所有镜头都“长一样”，要让剪辑点不跳。

03

肤色最后看关系

皮肤不应发灰、发绿或像独立贴在背景上。观察脸与环境的高光、阴影和色温是否属于同一光源。

04

每次只动一个维度

曝光、色温、对比、饱和度分别控制。一次改完四项，无法判断画面变好是因为哪一步。

05

在全片上下文中检查

切到相邻镜头、全屏播放，关注视线、运动与色彩节奏。单帧 Still 无法暴露闪烁和连续性错误。

06

用版本管理表达

技术修正、客户意见、风格实验与最终版分开保存。版本号、备注与时间比“final_final”可靠。

07LOOK DEVELOPMENT / 风格与质感
CREATIVE · 风格不是预设

风格是一组有意识的取舍，
不是把画面调到最重。

颜色分离、高光滚降、阴影色相、对比曲线、Halation 与 Grain 都可以构成风格。关键是它们如何服务题材、人物和观看方式，并且在不同镜头间保持一致。

01Foundation曝光 · 白平衡 · 技术转换
02Color Relationship肤色 · 环境色 · 冷暖分离
03Contrast Shape黑位 · 高光滚降 · Pivot
04TextureHalation · Bloom · Grain

先决定“什么颜色出现在哪里”，再决定“有多浓”。

很多 Look 看起来像滤镜，是因为只改了整体色偏，没有改变颜色之间的关系。真正有辨识度的风格通常包含：明确的主/辅色、面部保护、暗部倾向、高光品质和质感策略。

主体是否仍然清楚？肤色是否有可信的生命感？ 高光是否保留层次？暗部是否仍有信息？ 邻近镜头是否连续？风格是否服务故事？
SKIN / 01

保护面部的“关系”

不用把所有肤色拉到同一 RGB 值。优先保持高光过渡、环境反射和肤色间的自然差异；用限定器时先看 Matte。

SPACE / 02

让前后景不靠“亮暗”分离

主体与背景可以通过色相、饱和度、局部对比、光源颜色区分。空间感来自多层线索，不是单靠压暗背景。

TEXTURE / 03

质感要能解释

Halation 模拟高光在胶片中的扩散，Grain 影响微结构。强度应随镜头、输出尺寸和观看平台调整，避免默认拉满。

STYLE DIRECTION

同一条素材，不同的意图

A

克制自然

B

柔和高光、暖黄实用光、轻微 Halation 与颗粒，适合回忆、年代和浪漫叙事。

POCKET GLOSSARY

调色口袋词表

Color Management
定义输入、工作、显示和输出色彩空间的转换链路。
Working Space
调色运算所在的色彩空间或工作曲线。
ODT
输出显示变换，把工作空间映射到具体显示目标。
Power Window
控制局部调整空间范围的形状遮罩。
Qualifier
按色相、饱和度、亮度等选择颜色相似区域。
Layer Mixer
把并行节点或 Alpha 遮罩结果混合的节点。
Pivot
对比调整的支点位置，影响亮暗拉伸方式。
Halation
高光在影像结构中扩散形成的红橙色光晕。
LUT
查找表，能把输入颜色映射到输出颜色；需明确色彩空间和用途。
Gamut Mapping
把超出目标色域的颜色映射回可显示范围。

DIAGNOSE · 先旁路，再定位

画面不对时，
先从信号链找答案。

按色彩管理、源素材、节点、遮罩、跟踪与交付顺序诊断。问题不一定在最后一个工具上，很多“调不准”是输入空间或输出转换错了。

DEBUG RULE

每次只旁路一个节点，每次只改一个变量。先在 Still 中对比，再放到全片播放中验证；不要用更大的风格掩盖技术错误。

QCKNOWLEDGE CHECK / 三题自测
COLOR CHECK · 3 MIN

你能分辨
“问题”与“风格”吗？

答完立即得到解释。三题分别检查色彩管理、节点诊断和镜头匹配。

0/ 3 CORRECT
Q1 / COLOR MANAGEMENT

画面整体发灰，第一步最合理的判断是什么？

“灰”可能来自 Log 尚未正确转换、数据范围不匹配或输出映射问题。先验证信号链，再做审美判断。

Q2 / NODES

某个局部节点把边缘也改变了，最有效的第一步是什么？

出现边缘问题先验证选区本身。Matte 范围过大、羽化不合适或跟踪漂移，都会让局部调整扩散到不该影响的位置。

Q3 / SHOT MATCH

一场戏中每个镜头单独看都漂亮，但剪辑点会跳。正确做法是？

镜头匹配是关系工作。Hero Shot 提供基准，连续播放暴露明暗、色温和肤色跳变；每一镜单独“好看”并不等于场景成立。
